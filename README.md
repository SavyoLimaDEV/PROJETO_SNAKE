# Snake (C) — Projeto de estudo (Estruturas de Dados)

Este projeto é um **jogo da cobrinha (Snake)** feito em **C**, criado com o objetivo principal de **praticar e aprender Estruturas de Dados** e organização de código em módulos.

No início, o jogo será **100% em console (texto)**, sem imagens e sem interface complexa.  
Mais adiante, a ideia é evoluir para uma versão com **melhor visual** e possivelmente **sprites/imagens**.

---

## Objetivos do projeto

- Praticar **estruturas de dados** na prática (listas, filas/deques, arrays dinâmicos, etc.)
- Treinar **organização por módulos** (`.h` + `.c`) e boas práticas em C
- Implementar um jogo completo com:
  - loop de jogo (update + render)
  - entrada do usuário
  - colisões e regras
  - pontuação e dificuldade progressiva
